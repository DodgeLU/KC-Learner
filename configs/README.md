# Configs

`ednet_corrected/protocol.json` is the frozen corrected-EdNet protocol
`ednet_corrected_publication_v1`. The CLI loads it by default.

`ednet_dev5000_cohort.json` records the cohort hash and the selection
rule. The ordered user-id list is a local generated file and is not
packaged.

`project_c` is not part of this repository.
